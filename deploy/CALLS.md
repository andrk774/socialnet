# Личные звонки socialnet

Раздел `/calls`, кнопки в личном диалоге и профиле запускают WebRTC-звонок между двумя пользователями. Входящий вызов появляется на любой странице открытого socialnet. История хранится в PostgreSQL; очистка скрывает завершённые звонки только у текущего пользователя.

Микрофон и камера запрашиваются только после нажатия «Позвонить», «Видео» или «Принять». Для браузеров нужен HTTPS; `localhost` допускается для разработки. Сервер обменивается SDP через авторизованный API, аудио и видео не записываются. SDP очищается при завершении или обработке истёкшего вызова.

## Работа между сетями

Без ICE-серверов соединение возможно только там, где браузеры находят прямой маршрут. Для NAT/VPN и мобильных сетей настройте свой TURN (например, coturn с `use-auth-secret`). В `.env`:

```dotenv
CALLS_STUN_URL=stun:turn.example.org:3478
CALLS_TURN_URL=turns:turn.example.org:5349?transport=tcp
CALLS_TURN_SECRET=replace-with-coturn-static-auth-secret
```

Домен должен указывать на настроенный TURN-сервер с действительным TLS-сертификатом. У coturn должны быть открыты порты сервиса и настроенный диапазон relay-портов. Один и тот же секрет задаётся в coturn и API; браузер получает только временные HMAC-учётные данные сроком на час. Секрет не помещается в frontend или репозиторий. После настройки пересоздайте API: `docker compose up -d api`.

Проверьте звонок с двух аккаунтов в разных сетях, включая мобильную. Локальная проверка с виртуальными камерой и микрофоном не подтверждает работу внешнего TURN.

## Ограничения текущей версии

- Только личные звонки; конференции, публичные ссылки, планирование, запись и расшифровка не реализованы.
- Для получения вызова socialnet должен быть открыт. Фоновые push-вызовы отсутствуют.
- Вызов без ответа истекает через 60 секунд. Активный вызов закрывается при отсутствии heartbeat одной стороны более 90 секунд; максимальная продолжительность — 4 часа.
- Обновление страницы прерывает локальное медиасоединение. Возобновление и автоматическая смена сети не реализованы.
- История загружается страницами по 100 записей. Доступ к сигнализации есть только у участников; применяются блокировки и правила личных сообщений.

Основа протокола: [MDN — Signaling and video calling](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Signaling_and_video_calling).
