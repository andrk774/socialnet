# Люди рядом и переписка по Wi-Fi

Раздел `/nearby` доступен после входа. Кнопка «Разрешить геолокацию и стать видимым» объясняет публикацию местоположения и запрашивает разрешение браузера. Разрешение, выданное ранее другим функциям сайта, само по себе видимость не включает.

Видимость действует 15 минут, обновляется только по кнопке и выключается кнопкой «Скрыться». Сервер хранит координаты с округлением до 0,01 градуса, выдаёт только диапазон расстояния до 25 км. История перемещений не собирается. Истёкшие записи не показываются; новая позиция заменяет предыдущую. Блокировки действуют в обе стороны. Настройки допуска личных сообщений продолжают действовать.

## Общая локальная сеть

Мессенджер использует API и WebSocket того же сервера. Для локальной переписки внешний интернет не нужен: оба устройства должны открыть **один локальный сервер**, а база данных и сервер должны оставаться включёнными. Это не прямое соединение телефонов и не Bluetooth.

1. Подключите компьютер и телефоны к одной Wi-Fi-сети. В роутере отключите изоляцию клиентов для этой сети.
2. Узнайте локальный IPv4 компьютера командой `ipconfig`, например `192.168.1.20`. На телефоне `127.0.0.1` означает сам телефон, а не компьютер.
3. Для Kubernetes оставьте штатное подключение `127.0.0.1:8080`. Перед ним настройте HTTPS reverse proxy, слушающий локальный IP компьютера. Не открывайте PostgreSQL, Redis или Kubernetes API телефонам.
4. Например, Caddy на этом компьютере с конфигурацией ниже выдаёт локальный сертификат. Замените IP на свой. Корневой сертификат локального центра Caddy нужно установить как доверенный на каждом телефоне. Простого обхода предупреждения о сертификате недостаточно для надёжной работы геолокации.

```caddyfile
https://192.168.1.20 {
    tls internal
    reverse_proxy 127.0.0.1:8080
}
```

5. В конфигурации API установите `APP_URL=https://192.168.1.20`, `ALLOWED_ORIGINS=https://192.168.1.20` и `COOKIE_SECURE=true`, затем перезапустите API. Сохраните прежние значения, если понадобится вернуть прежний адрес.
6. Разрешите входящий TCP 443 в брандмауэре только для частной локальной сети. Если порт 443 уже занят другим приложением, используйте отдельный порт и укажите его и в URL, и в конфигурации API.
7. На обоих телефонах откройте HTTPS-адрес, войдите под разными аккаунтами и откройте «Сообщения». Для проверки отключите внешний интернет роутера, сохранив Wi-Fi, и отправьте сообщение в обе стороны.

Геолокация требует доверенного HTTPS и разрешения браузера; её получение без интернета зависит от устройства. Звонки могут требовать отдельного TURN-сервера. Внешние ресурсы, почта и внешние интеграции без интернета недоступны. На этой стадии проверка двух физических телефонов не выполнена.
