# Перенос музыки из открытого VK (экспериментальный)

1. Распакуйте архив расширения в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите эту папку.
3. В том же браузере войдите в VK самостоятельно и откройте свою музыку. Прокрутите список, чтобы записи загрузились.
4. Нажмите значок расширения и «Добавить записи». Для каждого плейлиста откройте его страницу, введите название в расширении и повторите сбор.
5. Откройте socialnet на `http://127.0.0.1:8080` или `http://localhost:8080`, войдите в свой аккаунт. В значке расширения разрешите перенос в эту вкладку.
6. В разделе «Музыка» раскройте «Импорт из открытого VK», получите список, выберите доступные записи и начните импорт.

Это не полный автоматический экспорт аккаунта. Помощник читает только загруженные элементы страницы с метаданными `data-audio`. Если текущий интерфейс VK их не содержит, список будет пустым. Плейлисты задаются вручную при сборе. Реальная совместимость с вашим аккаунтом требует проверки.

Переносятся только прямые MP3/M4A/OGG/FLAC/WAV до 50 МБ с разрешённых аудиодоменов VK. HLS, зашифрованные адреса, недоступные файлы и перенаправления не поддерживаются. Никакие ограничения доступа не обходятся. Используйте для аудио, которое имеете право переносить.

Недоступные записи можно экспортировать как названия и плейлисты в JSON. Это не добавляет воспроизводимые треки в socialnet. Поле `file` в JSON содержит предлагаемое имя MP3; при сопоставлении с собственными файлами его нужно исправить при необходимости.

Пароль, cookies и токен VK не читаются. Аудио скачивается расширением без cookies, затем отправляется обычной авторизованной загрузкой socialnet. Исходные адреса аудио не передаются странице socialnet. Разрешение действует для выбранной вкладки два часа. Каталог хранится в памяти сессии расширения; очистка каталога отзывает разрешение. После завершения расширение можно удалить.

Прогресс импорта хранится в localStorage socialnet отдельно для каждого аккаунта. Повтор использует сохранённые идентификаторы треков и плейлистов. При потере ответа на загрузку возможен дубликат. Не запускайте параллельные импорты в разных вкладках. Остановка прерывает скачивание из VK; уже отправленная загрузка в socialnet может завершиться.
