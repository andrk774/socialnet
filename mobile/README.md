# Приложение для Android

Оболочка сайта на [Capacitor](https://capacitorjs.com): внутри — тот же
интерфейс, что в браузере, загруженный с вашего домена. Обновления сайта
приходят сразу, без новой версии приложения. Своё у приложения одно, но
главное для походов: **трек пишется в фоне, при выключенном экране** (плагин
`@capacitor-community/background-geolocation`, уведомление «Идёт запись
трека»). В браузере для этого экран должен оставаться включённым.

## Сборка

APK собирает GitHub Actions — задание **android**
(`.github/workflows/android.yml`). Оно запускается при изменениях в
`mobile/` и вручную: Actions → android → Run workflow.

Перед первой сборкой в настройках репозитория (Settings → Secrets and
variables → Actions → Variables):

| Переменная | Пример | Зачем |
|---|---|---|
| `APP_URL` | `https://pohody-ural.ru` | адрес сайта, который откроет приложение |
| `APP_ID` | `ru.pohodyural.app` | идентификатор в магазине; **после публикации не менять** |
| `APP_NAME` | `Походы Урала` | подпись под значком |

Готовый APK — в разделе Artifacts прогона (`socialnet-debug-apk`). Скачайте
на телефон и установите (разрешите установку из этого источника).

## Подпись для RuStore

Отладочный APK годится для себя и друзей. Для магазина нужен подписанный
релиз. Ключ создаётся один раз и **хранится вечно**: без него обновить
приложение в магазине нельзя.

```bash
keytool -genkeypair -v -keystore release.jks -alias socialnet \
  -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks > release.jks.b64   # в Windows: certutil -encode release.jks release.jks.b64
```

Секреты репозитория (Secrets): `ANDROID_KEYSTORE_BASE64` (содержимое
`release.jks.b64`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`
(`socialnet`), `ANDROID_KEY_PASSWORD`. Сам `release.jks` и пароли
сохраните в менеджере паролей, в репозиторий не кладите.

С секретами прогон соберёт ещё и `socialnet-release`: подписанные
`app-release.apk` и `app-release.aab`.

## Публикация в RuStore

1. Аккаунт разработчика: https://console.rustore.ru (физлицо, самозанятый,
   ИП или юрлицо; нужна проверка личности или компании).
2. Новое приложение → загрузить `app-release.apk` (или `.aab`).
3. Карточка: название, описание, скриншоты телефона (можно снять в
   приложении), значок 512×512, категория «Спорт» или «Путешествия».
4. Политика конфиденциальности: `https://ваш-домен/legal/privacy`.
5. Разрешения: в описании для модерации объясните фоновую геолокацию —
   «запись GPS-трека похода по кнопке пользователя, пока идёт запись;
   постоянное уведомление; координаты сохраняются только в маршрут,
   который пользователь сам загружает».
6. Отправить на модерацию (обычно 1–3 рабочих дня).

Новая версия: прогон с секретами → загрузить новый релиз в консоли.
`versionCode` растёт сам — это номер прогона GitHub Actions.

## Локально (необязательно)

Нужны Node.js 22, JDK 21 и Android Studio (SDK).

```bash
cd mobile
npm install
APP_URL=https://ваш-домен node scripts/prepare.mjs
npx cap open android      # Android Studio: Run на подключённом телефоне
```

Папка `android/` создаётся скриптом и не хранится в репозитории.

## Если трек в фоне обрывается

Некоторые прошивки (Xiaomi, Huawei, Samsung) усыпляют приложения в фоне.
В настройках телефона для приложения: «Батарея → Без ограничений»,
«Автозапуск — разрешён». Геолокации достаточно «Разрешить при
использовании»: пока идёт запись, приложение работает как служба с
уведомлением, и это считается использованием.
