# Обновление мессенджера и перенос медиа

## Сообщения

Меню «•••» доступно у обычных сообщений. Свои сообщения можно редактировать и удалять у всех участников. Сервер проверяет отправителя и участие в диалоге; зашифрованные и уже удалённые сообщения не редактируются. Обновления отправляются всем участникам через WebSocket. Миграция `0044_message_edit.sql` добавляет отметки редактирования и удаления.

Ответ вставляет цитату в текст. Пересылка переносит **только текст**, без вложений и без подтверждённой ссылки на оригинал. «Важное» сохраняется в браузере отдельно для каждого аккаунта, пока без синхронизации между устройствами. Выбор нескольких сообщений позволяет скопировать их текст.

В поле ввода доступны фото с устройства, файл, музыка из первых 50 записей личной библиотеки, ссылка на свою геолокацию, эмодзи, свои стикеры и голосовая запись до 4 минут 50 секунд. Подсказки стикеров сопоставляют введённый текст с названием собственных стикеров. Браузер запрашивает разрешение на микрофон; сервер должен иметь FFmpeg для обработки записи.

Видеосообщение открывается кнопкой ▷ рядом с микрофоном. Можно записать видео с камеры либо выбрать файл, посмотреть запись и прикрепить её. Отправка выполняется обычной кнопкой сообщения. Нужны HTTPS/localhost, разрешение камеры и микрофона, MediaRecorder и FFmpeg на сервере. Ограничения: 60 секунд, 50 МБ, исходник до 4096 пикселей по каждой стороне; сервер готовит MP4 до 480×480. До отправки видео доступно автору, после — участникам чатов с этим вложением. Публичный видеокаталог и CDN для таких записей не используются. Миграция `0045_video_messages.sql` обязательна.

В меню «+» личного диалога есть «Подарок»: каталог сервера, цена в монетах, поздравление и отдельное подтверждение списания. Подарок попадает в профиль получателя и создаёт уведомление; отдельная карточка подарка в истории переписки пока не создаётся. Повтор запроса в открытом окне использует тот же ключ идемпотентности. При неопределённом результате сети проверьте подарки получателя, прежде чем закрывать окно и начинать новую отправку.

«Сервис» позволяет поделиться ссылкой на музыку, видео, фотографии или «Людей рядом» socialnet. Получатель видит кликабельную карточку. Это внутренние разделы socialnet, а не импорт мини-приложений VK. Поиск ограничен загруженными сообщениями. Подтверждённый online/last-seen не имитируется.

## Видео

На карточке готового видео доступны «Скачать MP4» и «Сохранить офлайн». Скачанный файл открывается обычным видеоплеером. Сохранённая внутри сайта копия открывается через `/offline` на том же устройстве и адресе сайта. Нужен готовый MP4; HLS-сегменты не скачиваются.

Копии хранятся в Cache Storage и удаляются при явном выходе из аккаунта. Очистка браузера или нехватка места может удалить их. Сохранённые копии доступны пользователю этого устройства офлайн; используйте отдельный профиль браузера на общем компьютере. Для Cache Storage нужен HTTPS или localhost. Большое видео загружается целиком в память перед сохранением.

## Музыка из VK

Импорт через музыкальный API VK **не подключён**: приложение и доступ к API не настроены. Есть экспериментальный [браузерный помощник](../tools/vk-music-bridge/README.md) для загруженных на странице записей и доступных прямых аудиофайлов; совместимость с реальным аккаунтом пока не проверена. Пароль, cookies и токены VK вводить в socialnet не нужно. Отдельный импорт ниже работает с локальными аудиофайлами и JSON-списком, который вы предоставляете.

В разделе «Музыка» раскройте «Импорт музыки и плейлистов из файлов». Выберите JSON и аудиофайлы, проверьте количество, затем нажмите «Импортировать».

```json
[
  {
    "file": "song.mp3",
    "title": "Название",
    "artist": "Исполнитель",
    "playlists": ["Любимое", "В дорогу"]
  }
]
```

Имя `file` должно точно совпадать с именем выбранного файла. Ограничения: до 1000 строк, JSON до 2 МБ; ограничения аудиозагрузки такие же, как при обычной загрузке музыки. Ошибки показываются отдельно для каждого трека. Плейлисты создаются заново, успешные загрузки при ошибке следующего трека не откатываются. Повторный импорт может создавать дубликаты. Записи без аудиофайла сохраняются только в исходном JSON, но не становятся доступными треками в socialnet.

Проверены API редактирования, права доступа и realtime, TypeScript-сборка и интерфейс редактирования в браузере. Реальный перенос библиотеки VK и запись с микрофона физического телефона требуют отдельных проверок.
